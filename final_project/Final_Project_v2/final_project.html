In this project, we aim to predict housing sale prices using a dataset from 2016-2017. We will perform extensive data cleaning and preparation, then build and evaluate three different regression models: a single regression tree, a linear model, and a random forest. The final goal is to select the best performing model and train it on all available data.

Regression Tree Modeling

Our first model is a single regression tree. Trees are great for their interpretability. We need to find the optimal nodesize, which controls the complexity of the tree. A smaller nodesize leads to a more complex tree, which can overfit.

Finding the Best nodesize

We’ll loop through different nodesize values, train a tree for each, and calculate the error on both the training data (in-sample) and the validation data (out-of-sample). The best nodesize is the one that minimizes the out-of-sample error.

# Set the maximum nodesize to test.
max_nodesize_to_try = 70

# Initialize vectors to store errors.
in_sample_errors = numeric(max_nodesize_to_try)
oos_errors = numeric(max_nodesize_to_try)

# Loop through possible nodesize values.
for (i in 1:max_nodesize_to_try) {
  tree_mod = YARFCART(data.frame(X_train), y_train, nodesize = i, calculate_oob_error = FALSE)
  
  # Calculate in-sample error.
  yhat_train = predict(tree_mod, data.frame(X_train))
  in_sample_errors[i] = sd(y_train - yhat_train)
  
  # Calculate out-of-sample (validation) error.
  yhat_select = predict(tree_mod, data.frame(X_select))
  oos_errors[i] = sd(y_select - yhat_select)
}
# Plot the errors to visualize the trade-off.
ggplot(data.frame(
  nodesize = 1:max_nodesize_to_try,
  in_sample_errors = in_sample_errors,
  oos_errors = oos_errors
)) + 
  geom_point(aes(x = nodesize, y = in_sample_errors), col = "red") +
  geom_line(aes(x = nodesize, y = in_sample_errors), col = "red") +
  geom_point(aes(x = nodesize, y = oos_errors), col = "blue") +
  geom_line(aes(x = nodesize, y = oos_errors), col = "blue") +
  labs(
    title = "In-Sample (Red) and OOS (Blue) Error vs Nodesize",
    x = "nodesize",
    y = "Standard Deviation of Error"
  ) +
  theme_minimal()

The blue line (out-of-sample error) shows the sweet spot. We choose the nodesize that gives the minimum error on the validation set.

# Find the nodesize that minimizes the out-of-sample error.
best_nodesize = which.min(oos_errors)

Regression Tree Performance

Let’s evaluate the performance using Root Mean Squared Error (RMSE) and R-squared (R²).

In-Sample Performance

# Predict on the training data.
y_hat_train_select = predict(tree_mod, X_train_select)

# Calculate in-sample RMSE and R².
rmse_train_select = sqrt(mean((y_train_select - y_hat_train_select)^2))
ss_res_train_select = sum((y_train_select - y_hat_train_select)^2)
ss_tot_train_select = sum((y_train_select - mean(y_train_select))^2)
r2_train_select = 1 - ss_res_train_select / ss_tot_train_select

cat("In-sample RMSE:", rmse_train_select, "\n")
## In-sample RMSE: 40496.21
cat("In-sample R²:", r2_train_select, "\n")
## In-sample R²: 0.9476025

Out-of-Sample Performance

Now for the true test: performance on the unseen test data.

# Predict on the test data.
y_hat_test = predict(tree_mod, X_test)

# Calculate out-of-sample RMSE and R².
oos_rmse_tree = sqrt(mean((y_test - y_hat_test)^2))
ss_res = sum((y_test - y_hat_test)^2)
ss_tot = sum((y_test - mean(y_test))^2)
oos_r2_tree = 1 - ss_res / ss_tot

cat("Out-of-sample RMSE:", oos_rmse_tree, "\n")
## Out-of-sample RMSE: 75999.5
cat("Out-of-sample R²:", oos_r2_tree, "\n")

Random Forest Modeling

Finally, we build a random forest model. Random forests are an ensemble of many decision trees and are known for their high predictive accuracy. We need to tune the mtry hyperparameter, which is the number of features considered at each split in a tree.

Finding the Best mtry

We will use the randomForest package to tune mtry. We’ll loop through all possible values of mtry, train a forest, and find the one that gives the lowest RMSE on our validation set.

library(randomForest)
# Combine training data for the randomForest function format.
df_train = data.frame(X_train)
df_train$sale_price = y_train

df_select = data.frame(X_select)
df_select$sale_price = y_select

p = ncol(X_train)  # number of predictors
num_trees = 1200
oos_se_by_mtry = numeric(p)

# Loop over mtry from 1 to p.
for (m in 1:p) {
  rf_model = randomForest(sale_price ~ ., data = df_train, ntree = num_trees, mtry = m)
  y_hat_select = predict(rf_model, newdata = df_select)
  oos_se_by_mtry[m] = sqrt(mean((df_select$sale_price - y_hat_select)^2))  # RMSE
}

# Create a data frame for plotting.
df_mtry = data.frame(
  mtry = 1:p,
  oos_rmse = oos_se_by_mtry
)

# Plot OOS RMSE vs mtry.
library(ggplot2)
ggplot(df_mtry, aes(x = mtry, y = oos_rmse)) +
  geom_point() +
  geom_line() +
  labs(
    title = "OOS RMSE vs mtry (1200 Trees)",
    x = "mtry (Number of Features Tried at Each Split)",
    y = "Out-of-Sample RMSE on Select Set"
  ) +
  theme_minimal()

# Find the best mtry.
best_mtry = which.min(oos_se_by_mtry)
cat("Best mtry based on OOS RMSE:", best_mtry, "\n")
## Best mtry based on OOS RMSE: 4

Final Random Forest Model

With the optimal mtry found, we train our final random forest model using the YARF package, which is optimized for performance. We’ll train it on the combined training and validation data.

Shipping Final Model
